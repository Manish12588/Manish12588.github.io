Things I built to prove the skills

Featured · Playwright and CI/CD

QABank

A small banking app (REST API and web UI) in Docker, made as a stable target for test automation, with a separate Playwright and TypeScript suite of 50 tests. A GitHub Actions pipeline tests every pull request and promotes manually through DEV, QA and STAGE, publishing the reports to GitHub Pages.

  • 31 API and 19 UI tests, tagged smoke or regression
  • Smoke on DEV and STAGE, full regression on QA
  • STAGE waits for a manual approval
  • HTML and reportingLabs reports on every run
  • A demo script plants a bug to show the check going red
  • Each stage only starts if the one before it passed

DEV, QA and STAGE are simulated: one Docker image, with a different port and test selection per stage. The point is the promotion logic, the approval gate and the reporting.
